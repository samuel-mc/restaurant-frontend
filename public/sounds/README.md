# Alerta sonora de cocina / mesero

Incluido en el repo: `ping.wav` (+ `ping.m4a` de respaldo).

El hook `useKitchenAlertSound` prueba en este orden:
1. `/sounds/ping.wav`
2. `/sounds/ping.m4a`
3. `/sounds/ping.mp3` (si lo agregas después)

Tras el primer toque en la tablet, desbloquea autoplay del navegador.
